# UI fonts

- Lora 500–600: headings. Source and license: https://github.com/google/fonts/tree/main/ofl/lora
- Nunito 400–600: interface text and figures. Source and license: https://github.com/google/fonts/tree/main/ofl/nunito

Unmodified variable WOFF2 files from the Google Fonts CSS API, served locally.
Latin, Latin Extended and Vietnamese subsets, plus Nunito's infinity glyph, are included. Licenses are in
`lora-OFL.txt` and `nunito-OFL.txt`. No font account or external request is needed at runtime.
